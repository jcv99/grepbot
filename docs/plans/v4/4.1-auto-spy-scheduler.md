are part of the existing audit belt-and-braces (plan 26 I14).

Nothing in `src/` sends a spy. Plan 27 §9 lists 15 already-shipped items; spy
sending is **not** one of them. The closest analogues that exist and inform
this plan:

## 2. Gap

A scheduler that picks a ranked target and sends a spy. Three concrete
absences:

1. **No send route.** There is no `bridgePost('spy', payload, cb)` and no
   `gbAjaxWatch('spy:send', …)` registration. The TPL_FEATURE_MAP has no
   `spyTpl` slot. Sniffing is the first work item.
2. **No target ranking.** `state.findings` exists, `state.watchlist` exists
   (`src/intel.js:186-203`), but no module turns "I have 200 findings and a
   watchlist of 5 towns" into a ranked spy queue.
3. **No cadence.** The orchestrator has no `spy` key (`src/qol.js:388-432`).
   Spy is **scout-class** (HIGH-RISK-adjacent because it spends silver and
   can return a captcha), so it wires into `orchTick` with a long base
   cadence (≥ 30 min) and a tight per-target gap (≥ 20 min).

The plan therefore is not a refactor — the read path is already in place
and well-understood. The plan is a new scheduler on top of `src/spy.js`,
a new orchestrator hook, and a new template slot. The dry-run +
confirm-gate + captcha-key scaffolding mirrors `src/favor.js:52-152` for
reuse.

## 3. Design

The scheduler runs through `orchTick` (`src/qol.js:421-432`) under a new
`spy` key. Each tick:

1. Read `state.spyCfg` (default `{ targets: [], autoWatchlist: true,
   autoTopReported: 5, perCycle: 1, minGapMs: 1200000, dryRun: true,
   confirmOncePerCycle: true, maxConcurrent: 3, useFavor: false }`).
2. **Rank** the candidate pool. Pool = `state.spyCfg.targets` (manual pins) ∪
   `state.watchlist` (when `autoWatchlist`) ∪ top-N most-reported players by
   `state.findings` over the last 24h (when `autoTopReported > 0`).
   Score for a target `t`:
   `score(t) = (now - lastSpyAt(t)) * 1.0 + watchBonus(t) + reportBonus(t)`
   where `watchBonus` is `+1000` if `t.id` matches any `state.watchlist`
   rule, and `reportBonus` is `+100 * max(0, reportsIn24h(t) - 1)`. A
   target with no `lastSpyAt` starts at `now - 7d` (very stale → high
   score). A target whose `lastSpyAt` is within `minGapMs` is dropped.
3. **Drop** anything that already has an `enRoute` count ≥ `maxConcurrent`
   (read from `state.spyInFlight`, an `Object.create(null)` keyed by town
   id, incremented on send and decremented on bridge settle).
4. **Pick** the top-`perCycle` survivors. If `confirmOncePerCycle` and the
   last confirm-dialog has not been shown in this session, render a
   `confirm()` listing the top-3 (id + coord + score) and bail on cancel.
5. **Send** through `bridgePost('spy', payload, cb)` (`src/bridge.js:190-193`).
   The payload is **not** invented here — see §7 (sniff first).
6. **Reconcile** on bridge settle: success → `state.spyInFlight[townId]--`,
   `lastSpyAt[townId] = now`, `save(STORE.SPY_HISTORY, …)`; captcha →
   `captchaTrip('spy', …)` (auto via `captchaPaused`); error → log once
   and `gbRemember('spy', townId, 'error')` if `jrnHard(err)`.

The `lastSpyAt` table lives in `state.spyLastSpy`, persisted under
`STORE.SPY_HISTORY` (world-scoped). The `enRoute` table is **not** persisted;
it is rebuildable from the bridge in-flight registry (`src/bridge.js:131-147`).

Sniff discipline: the spy route is **not known today**. Plan 27 §13 is
explicit that a new post surface is `'sniff <x> via gbAjaxWatch(sig, settle)',
capture the template into TPL_FEATURE_MAP` — an explicit unknown, not a
guess. See §7.

## 5. State & storage

| Key | Type | Persisted | World-scoped | Notes |

| `state.spyEnabled` | boolean | `STORE.AUTO_SPY` | yes (per-host) | Toggle (mirror of `state.autoFarm`) |
| `state.spyCfg` | object | `STORE.SPY_CFG` | yes | Per-host config; redacted on export |

| `state.spyInFlight` | `{ [townId]: number }` | — | no | Bridge in-flight counter, rebuilt on settle |

`STORE.SPY_HISTORY`, `STORE.SPY_CFG`, `STORE.AUTO_SPY`, `STORE.SPY_TPL` go
into `WORLD_SCOPED_BASES` (`src/header.js:193-214`). Prune TTL: `spyLastSpy`
rows are pruned at 7d in a new module-local cleanup pass inside `spyCycle`
(prototype: `Object.keys(state.spyLastSpy).forEach(k => { if (now -
state.spyLastSpy[k] > 7*86400000) delete state.spyLastSpy[k]; })` followed
by one `save(STORE.SPY_HISTORY, state.spyLastSpy)`). The pass is throttled
to once per hour via a module-local `lastPruneAt`.

`configVer` bump: `10 → 11` (entry 14).

## 7. Post surface & safety

**Unknown route — explicit sniff work item.** The bridge action name + payload
for sending a spy is not in `src/` today. The work item is:

```text
1. Hand-trigger a spy by opening a town info popup → "espiar" → choose
   resource mission → Send. The XHR spy at src/spy.js:37-112 captures the
   raw POST url + body in hookFetch / hookXhr.
2. gbAjaxWatch('spy-send', settle) is registered by spyCycle before the
   first bridgePost; the XHR spy settles it from the raw response on
   loadend (src/spy.js:73-82).
3. The captured url + body shape is stored in state.spyTemplate and
   mirrored to STORE.SPY_TPL. tplNameFor('spy', payload) returns 'spyTpl'
   (src/core.js:795-801).
4. Until the sniff lands, spyCycle never fires (state.spyTemplate == null
   triggers a one-shot gbLogT('spy-no-tpl', 300000,
   'spy: no template learned — hand-spy once to capture')).
```

Lock: `gbLock('spy', 180000)` (entry 5). One lock per cycle, not per
target — the per-target `enRoute` count lives in `state.spyInFlight`.

gbCaptchaPause feature key: **`'spy'`** (entry 6). `captchaTrip('spy', …)`
is called by `bridgePost`'s classify path (`src/bridge.js:110-127`) on a
captcha response and the captcha ladder (`src/core.js:1337-1350`) takes over
with 5/15/60min backoff.

Dry-run (`state.spyCfg.dryRun === true`): the cycle logs `DRY-RUN spy: {…}`
(`src/bridge.js:215-219`) and journals `skip:dryrun`
(`src/core.js:457-461`). The bridge post does not fire. The ranker still
runs and the top-3 confirmation dialog still appears.

Confirm-gate: `confirmOncePerCycle` (default ON) wraps the first
`bridgePost` of each session in a `confirm('¿Espiar X / Y / Z?')` dialog
(Spanish UI, CLAUDE.md). Once accepted, the session accepts the rest
without prompting.

Precondition invariant: every guard reads a value it actually read. The
ranker drops targets whose `lastSpyAt` is unreadable by treating them as
fully stale (score = `now - (now - 7d)` = `7d`). The `enRoute` count is
read from `state.spyInFlight` (built by the same module). The
`reportsIn24h(t)` falls back to `0` when no finding matches.

## 8. Failure modes

| Condition | Verdict | Behavior |
|---|---|---|
| `state.spyTemplate` is null | `gbLogT` once, no fire | Per §7 |
| `state.spyCfg.targets` is empty AND `autoWatchlist` is false AND `autoTopReported = 0` | log once, return | No candidates — nothing to do |
| `confirmOncePerCycle` dialog cancelled | exit the cycle | `enRoute` count unaffected (no send) |
| `bridgePost` errs `'budget'` | re-queue at next tick | Orchestrator's adaptive cadence widens (4 idle runs → 8×, `src/qol.js:415-419`) |
| `bridgePost` errs `'captcha'` | `captchaTrip('spy', …)` | 5/15/60 ladder; orchestrator's `ORCH_CAPTCHA` (`src/qol.js:404-408`) blocks the tick |
| `bridgePost` errs `'timeout'` | log once, no retry | Inherited from `src/bridge.js:101-104`; irreversible action — no timeout-fallback |
| 3 consecutive hard errors on `spy:<townId>` | `gbRemember('spy', townId, err)` opens a 5/15/60min skip | `state.decisionSkips` (`src/core.js:463`) — same shape as other features |
| `minGapMs` violated by a tier race | `spyCycle` re-checks `lastSpyAt` before fire | Skip + log once |
| Unknown `r.type`/JSON shape | `parseReport` returns null; existing `reportFetchFail` path | `src/spy.js:258-264` already handles |
| `state.spyEnabled` toggled mid-cycle | next `orchTick` skips | `orchFeatureEnabled` (`src/orchestrate.js:1-18`) gates |

The five `return null` strictness paths in `parseReport` are unchanged.
A spy *response* with missing units / missing town is still a valid spy
report — `parseReport` already accepts `r.attacker` + `r.defender` only
without units (`src/parse-inline.js:53-55`).

## 9. Validation gate

Plan 27 §11 Med risk: dry-run + one hand-triggered firing + one full
orchestrator tick.

1. `grepbot.user.js` rebuilt. Install via Tampermonkey paste.
2. Open Config → `Espiar automáticamente` OFF. Verify `state.spyEnabled`
   persists across reload (UI toggle).
3. Open Config → `auto top 24h = 5`, `perCycle = 1`, `dryRun = true`. Save.
   Preflight shows `auto-spy: dry-run` row (existing preflight row at
   `src/stats.js:171-172` is the wiring precedent; add a new row mirroring
   it). Log: `spy: template pending — hand-spy once to capture`.
4. Hand-spy one target by opening the town's spy popup → send. The XHR
   spy captures the route; `state.spyTemplate` populates;
   `gbLogT('spy-template', 60000, 'spy: template learned')` fires once.
5. Toggle `Espiar automáticamente` ON. Orchestrator fires after 30min
   (`ORCH_CADENCE.spy = 1800000`). Confirm-gate dialog lists the top-3
   ranked targets. Accept. Log: `DRY-RUN spy: <townId> → <payload>`.
   Journal: `skip:dryrun` for `spy` feature.
6. Disable `dryRun`. Wait 30min. Confirm. The bridge fires. Log: `spy:
   sent <townId>`. `state.spyLastSpy[townId] = now`. Stats tab shows
   `spy` row in the journal rollup.
7. Hand-trip a captcha. Confirm the 5/15/60 ladder opens and the
   orchestrator gates `spy` per `ORCH_CAPTCHA.spy`.
8. Force the dry-run flag back ON. Toggle the toggle 5× in 60s. Log
   shows `spy: toggle changed` once (throttled), no send.

## 10. Out of scope

- **Spy route sniff.** Captured by the work item in §7. Once learned,
  it lives in `state.spyTemplate` and `STORE.SPY_TPL`. A separate
  plan-of-record tracks the sniff attribution.
- **Hero transfer / assignment (plan 4.3).** 4.1 picks targets; 4.3 owns
  the hero UX.
- **Spy-queue as a watchlist UI.** The Intel tab shows the top-3 ranked
  targets (entry 10) but does not let the user drag-reorder — that is a
  v4.3 UX plan.
- **Favor-driven spy.** `state.spyCfg.useFavor` is a flag (default `false`).
  Wiring it to `src/favor.js:favorCurrent()` is a separate plan.
- **Per-target model payload capture.** The scheduler learns one
  `(townId, payload)` shape and reuses it; if the bridge invalidates
  due to a `payload_stale` (`state.tplHealth.spyTpl.invalidated`),
  the next cycle re-sniffs. `tplHealthOk` gates the fire
  (`src/core.js:857-880`).
- **Spy counter / silver spent panel.** Stats tab gets a `spy` rollup
  row inherited from the journal (`src/core.js:463-500`) but a styled
  "silver spent on spies" widget is a v4.3 plan.
- **Export redaction of `spyCfg.targets`.** v4.0 mirrors `favorCfg`
  behavior (no redaction). Follow-up in v4.1.
