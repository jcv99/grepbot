# Coverage audit, 2026-08-14

Two half-audits:

1. **MCP → bot:** every relay cmd in `src/relay.js` exposed as an MCP tool.
2. **Bot → player:** every Grepolis in-game action the bot automates, mapped
   to a relay command and an MCP tool.

Goal: prove `mcp ⊇ bot ⊇ player(automatable)` and surface what's missing on
each side.

## Verification re-runs

After adding a relay cmd, re-run:

```sh
./tools/relay-mcp/scripts/check-parity.sh
```

The script prints `parity OK: N commands, 100%` on success and exits 1
with a symmetric diff (commands only on the bot side, commands only on
the MCP side) when parity breaks. It compares:

- Bot side: `awk '/RELAY_CMDS = \{/,/^    \};/' src/relay.js | grep -oE "^      [a-z_]+: \{" | sed 's/^      //; s/: {$//' | sort -u` (see `tools/relay-mcp/scripts/list-relay-commands.sh`).
- MCP side: `grep -oE "cmd: '[a-z_]+'" tools/relay-mcp/src/commands.ts | sed "s/cmd: '//; s/'//" | sort -u`.

Adding a relay cmd without a matching MCP tool (or vice versa) is a
CI failure — wire both sides together.
