## 5. Hard constraints (apply to every task)

- **NO SERVER.** Paste-only Tampermonkey. No `server.py`, no
  `127.0.0.1:*`, no `/api/*`, no `npm`.
- **Bridge only.** All writes via `bridgePost` → `txRun`. New write
  features register in `TX_WRITE_FEATURES` (planner.js).
- **Probe semantics.** `gbNum` only. `+x + isFinite` is forbidden.
  Unreadable → `blind`, journal once, em dash on UI.
- **HIGH-RISK default OFF.** recruit / dodge auto / favor / god spells /
  support send / dump / emergency cave / attack / reinforce / spy-send /
  trade. Per-action opt-ins for any smart-auto.
- **Decision memory.** ring 400, 7-day TTL, batched save 5s, flush on
  pagehide. Identical decision+result bump `n`; three consecutive hard
  errors open 5/15/60min skip window.
- **Coalescers.** `*Soon` inside per-item sweeps; `txSave` deliberately
  NOT debounced.
- **UI language.** Spanish for panel; machine surface stays English.
- **Repaint.** `gbPaint(host, build, {key})` only. No bare
  `replaceChildren()`.
- **innerHTML.** literal-only via `gbLit`; wire values via
  `textContent`. No `gbSafe` / DOMPurify.
- **Lock registry.** `gbLock`/`gbUnlock`/`gbLocked` only. 10s sweep.
- **Templates.** learned per feature, never shared (`supportTpl ≠
  attackTpl` on purpose).
- **Snapshot.** `structuredClone`, never
  `JSON.parse(JSON.stringify(...))`.
- **One IIFE.** module order locked by `build.py` MODULES.
- **Version discipline.** every behavior change bumps `@version` in
  `src/header.js` → `python3 build.py` →
  `tests/artifact_surface.py` → smoke optional → commit (one version =
  one logical change) → tag.
- **In-game validation.** dry-run + es146 evidence required to claim any
  write side live-safe. Build success ≠ write safety.
